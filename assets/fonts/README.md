# Bundled fonts

- **Inter.ttf** — [Inter](https://github.com/rsms/inter) by Rasmus Andersson,
  licensed under the [SIL Open Font License 1.1](https://openfontlicense.org/).
  Bundled so the app renders in the same typeface as y-knot.io even on machines
  where Inter isn't installed. Registered privately at runtime by `fonts.py`.
